# Notice

EIRM contains Project source code, the AMI-Simulator research package, and
three small checkpoint groups: Practical-RIFE `flownet.pkl`, the E2VID
lightweight checkpoint, and the paper policy files under
`KEEP_PAPER_WEIGHTS_DO_NOT_DELETE/`. It does not include external source
checkouts, datasets, or generated event artifacts.

The adapter interfaces reference Practical-RIFE, DVS-Voltmeter, V2E, and ESIM.
Those projects remain separately obtained dependencies governed by their own
licenses and terms. Consult [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md) before
using those integrations.
